# 远程工作区面板美化 · 方向初稿

> 依据项目现有 UI（`lib/client/client.styles.js` + `docs/ui.md` + `client.locale.js` 的真实文案）做美化。
> 所有方向共用同一套真实内容、同样的三个 tab（主机 / 工作区 / 设置）、同样的交互状态。
> 这是给用户选方向的初稿，**选定后才做正式实现**。

## 用户的决定（逐字）

- 第一轮看了三版（Rams / Linear / 白盒）后：「再出3版让我挑选」
- 第二轮看了三版（硬件面板 / Swiss / 功能主义）后：「**rams先保留，再出3版rams的配色，其他风格的设计，除rams的先删除**」

据此：保留 dir-1-rams；删除其余五版；用**完全相同的 Rams 配色**，做三种不同骨架/风格的设计。

## 共同 spec

- 项目：dsh-ssh-workspace 的「远程工作区」侧边栏面板，高密度、带大量状态（连接 / 密钥 / 重连 / 转发 / 诊断）的运维控制台。
- 受众：开发者，在 DSH 里管理 SSH 主机、远程工作区、端口转发。长期看、频繁点，对信息密度与状态可读性敏感。
- 情感基调：可信、精准、专业。
- 输出：单文件 HTML 高保真原型；1440 宽视口里可切「侧栏 400px」与「细节 980px」两个视图；深链 `#hosts` / `#work` / `#set`，加 `-wide` 看宽视图。
- 约束：**Rams 配色 token 三版逐字相同**；只改骨架、密度、分区方式。沿用真实文案与状态语义（绿/黄/红不可乱用）。

## Rams 配色（三版完全一致，来自 dir-1-rams）

底色 `#f7f7f5`、衬底 `#ffffff` / `#f0f1ee` / `#e8e9e5`、边框 `#d3d5d0` / `#c2c5bf`、正文 `#191b1c`、次级 `#595e61`、弱 `#868b8d`；
唯一强调色蓝 `#1a5fb4`（hover `#164e93`）；状态色 success `#0b6e46`、warn `#8a5a00`、danger `#a52a20`（各自带浅底与描边）。
字体 system-ui + 等宽 Mono；正文 14px、标签 12px；发丝线、单一强调色、状态用形状+颜色双编码。

## 三版骨架（同配色，不同设计）

### 1. Ledger 账本式 · `dir-rams-ledger.html`
- 骨架：无卡片填充，只有发丝线与对齐的列——像一份可核对的主机清单。
- 每行的起点是一道 2px 的索引刻度（不用编号），地址变成蓝色可点的链接感，操作按钮左对齐贴着内容。
- 密度最高，适合「一眼扫完所有主机」。

### 2. Panels 分组面板 · `dir-rams-panels.html`
- 骨架：每个分区是一块浅色衬底面板，主机是带 1px 边框的独立小卡，标题挂在左上角；卡片内部用一道发丝线把「信息」与「操作」分开。
- 呼吸最大、字重层级最清楚（标题 22px / 主机 15px / 标签 12px），宽视图下表单可两列。
- 适合「每张卡片要读清楚、操作要稳」。

### 3. Rail 侧轨导航 · `dir-rams-rail.html`
- 骨架：tab 从顶部移到左侧，成为竖排导航；内容区独立在右，选中项用左侧 2px 竖条 + 浅底标识。
- 窄屏（<620px）自动回落成顶部横向 tab，所以真实侧栏里无副作用。
- 是三版里骨架变化最大的一版——同样的内容被重新分区，而非换皮。
