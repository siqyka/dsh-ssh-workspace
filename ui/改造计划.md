# 把 `ui/` 原型的风格落进真实面板

> 对象：[远程工作区面板-美化版.html](./远程工作区面板-美化版.html)（原型，单文件 6 界面）。
> 目标：把原型的**视觉语言与版式**搬进插件真实面板（`lib/client/*`），不改变任何行为语义。
> 结论先说：皮肤层已经有九成一致，真正要做的是 **4 处结构 + 1 套窄栏网格 + 2 处减法**，不是重做一套主题。

---

## 0. 为什么"皮肤层已经一致"

原型不是凭空画的：它是从 `docs/ui.md` 的描述 + 真实 `--sshwsp-*` 令牌长出来的。所以下面这些**不需要改**：

| 项 | 原型 | 现状 |
| --- | --- | --- |
| 居中列 | `max-width:980px; margin:0 auto; padding:72px 24px 40px`（`ui/远程工作区面板-美化版.html:52`） | `lib/client/client.styles.js:223` 逐字相同 |
| 容器查询断点 | `<420px` / `<320px`（原型 `:54`、`:83`） | `client.styles.js:880`、`:886` 同断点 |
| 卡片发丝线 | `1px solid #0000001a`（原型 `:133`） | `--sshwsp-border` = `--dsw-alias-border-l2`（`client.styles.js:246`） |
| 卡片圆角 | `--r-md:8px`（原型 `:22`） | `--sshwsp-radius-sm` = `--dsw-radius-sm`（同为 8px） |
| Tab 下划线 | 2px、`left/right:12px`、选中加粗（原型 `:108`） | 2px、`left/right:9px`、`font-weight:600`（`client.styles.js:277`） |
| 四个 tab 及顺序 | 主机 / 工作区 / 审计 / 设置 | `PANEL_TABS = ['hosts','workspaces','audit','settings']`（`lib/client/client.panel.js:338`） |
| 队列浮层宽 | 400px（原型 `:288`） | `width:400px`（`client.styles.js` queuepanel 段） |
| 截断/等宽数字/滚动条 | — | 已有 `tabular-nums`、`scrollbar-color: var(--sshwsp-track)` |

**一个必须记住的事实**：宿主的浅色主题里 `bg-base` / `bg-layer-1..3` **四层都是 `#fff`**（`app.asar` 的 `--dsw-static-neutral-bluish-00`），深色才是 `#151517 / #232324 / #2c2c2e / #353638`。所以：

- 浅色下"白卡 + 发丝线"是**现状就有的效果**，不用改填充；原型 `:16` 的 `--stage:#f9fafb` 是演示舞台，宿主侧栏里没有这一层，**不要照搬**。
- 深色下卡片用 `layer-2` 比底亮一档，关系是对的，**不要改成 `layer-1`**（会变暗）。

结论：**卡片填充、圆角、字号、居中列都不动**。观感差异来自别处——

1. 面板常常挂在**窄侧栏**里，980px 居中列用不上，一套 flex 行在 380px 下全部塌陷（这是"看起来不像原型"的主要原因）；2. 主机卡把「电源开关 / 自动连接勾选 / 测试 · 断开 · 立即重连 · 忘记密钥 · 浏览目录 · 编辑 · 删除」全塞进一个会换行的 flex 行，行数一多就散；
3. 审计是 6 段内联文本，没有列、没有表头、没有扫读轴；
4. 长说明常驻占版面，或用 `title` 兜着（`title` 不可聚焦、触屏不可用、出现有延迟）。

### 原型里有、但不要照搬的三处

1. **审计的「工作区」列**：`/audit` 行只有 `sessionId`，没有 workspace 名。要做也能做（筛选项已经维护 `workspace.sessionIds` 的反查），但筛选项已经回答了同一个问题，列是重复信息 → **不做**。
2. **六个界面的切换器 / 演示顶栏 / `.dw` 拖宽手柄**：演示壳，不是产品。
3. **`--stage:#f9fafb` 舞台色**：宿主浅色四层同色，侧栏没有第二层背景，硬画会跟宿主分叉。

## 2. 约束（改之前必须知道）

来自 `tests/presentation-tokens-smoke.mjs`（这六条会直接把方案打回）：

1. 规则体里**不许出现裸色值**，也不许直接读 `--dsw-*`（只有令牌块和 `hl-*` 例外）。
2. 每个 `border-radius` / `font-size` / `z-index` / `outline-width` 必须来自 scale 令牌。
3. 新增 portal 根必须加进 `client.styles.js:60–70` 的选择器列表，否则该面板**静默丢全部令牌**。
4. 浅色层 `body:not([data-ds-dark-theme])` 目前只覆盖 6 个令牌（`:324` 逐项核对）；加第 7 个要同步文档与断言。
5. 每个可点类必须在表里声明，并且**同时**有 hover 与 focus-visible；每个动画必须进 `prefers-reduced-motion` 关闭块；数字文本必须 `tabular-nums`。
6. 容器查询必须**窄的在后**（`:880` 在 `:886` 之前），且不得样式化容器自身。

另两条事故预防：

- 样式表整体在模板字面量里，**注释里不得出现裸反引号**（`docs/ui.md:986` 记过一次真实发布事故）。
- 桌面/窄栏都要看：`@container sshwsp-panel` 只对 `.sshwsp` 内部生效，**portal 出去的面板（队列、对话框、编辑器）不吃这条查询**，窄栏结论必须直接压 `.dialog` 宽度得出。

## 3. 分阶段计划

每阶段独立可交付、可回滚；顺序按"先能看见、再改结构、最后做减法"。

### P0 预览与验收地基（可选但强烈建议，0.5 天）

现在没有任何办法在 DSH 之外看到真实面板：`tests/support/render.mjs` 只产出元素树（无 DOM），宿主里看又无法截图对比。建一个只读预览脚本：

- `scripts/preview-panel.mjs`：用 `tests/support/client-source.mjs` 的 `clientPartSource()` 取 `client.styles.js`，按 `tag.textContent = \`` 标记切出样式表（与 `presentation-tokens-smoke` **同一切法**，因此"预览看到的表"必然等于"发布出去的表"）；用 `tests/support/render.mjs` 渲染真实 pane 函数，配上 `tests/` 里现成的 status fixture（4 台主机：已连接 / 已断开 / 重连中 / 已停用；3 个工作区：已挂载 / 已停用 / 主机已删；12 行审计）。
- 输出 `.tmp/preview/panel.html`：三个宽度档（1200 / 760 / 380，用 `iframe` 并排）+ 浅深两套（`body[data-ds-dark-theme]`）。
- `--shot` 分支调本机 Chrome headless 出 PNG（`--headless=new --screenshot --virtual-time-budget=2000`；无头有约 500px 最小视口，380px 档要用 iframe 内嵌而不是 `--window-size`）。
- `npm run preview` 挂上去；`.tmp/` 已在 `.gitignore`。

**验收**：一条命令出 6 张图，图里能看到真实 DOM 的四个 tab。

> 不做这步的替代方案：改完在 DSH 里肉眼看。慢，且"和原型像不像"无法作为验收证据。这一步是后面每阶段验收的基础设施。

## 6. 顺序与理由

```
P0 预览 ──┬─> P1 原语 ──> P2 主机卡 ──> P6 对话框/队列 ──> P7 文档
          └─> P3 工作区 ──> P4 审计 ──> P5 提示
```

- **P0 先做**：没有它，后面每一步都只能"我看着还行"，而这份仓库的验收文化是反过来的（先有证据，再谈好看）。
- **P1 → P2 → P3**：先改不碰 DOM 的，再改主面板里最显眼的两张卡，控制一次只坏一处。
- **P4 独立**：审计是纯列表，可以并行做；它也是这次改动里唯一需要重排 DOM 顺序的地方。
- **P5 压后**：减法一旦先做，后续结构调整会被"文字挪走了、但位置还没定"卡住。

总工时约 **4 天**（含预览脚本）；其中 P1/P6 是纯 CSS，半天内可回滚。
