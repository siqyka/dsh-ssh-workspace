## 1. 浅色 / 深色各看一遍

切换宿主主题（设置里切，不要只改系统主题），每次切换后**不重载页面**，直接看面板有没有跟着变。

看这 8 个地方，每个都在两种主题下过一遍：

| 位置 | 看什么 |
|---|---|
| 面板正文 | 文字不是纯黑压纯白；`--faint` 的辅助行（时间戳、来源）仍能读 |
| 主机卡片 | 边框可见但不抢；卡片底色比面板底色浅一档 |
| 浏览器对话框 | **原生下拉框（`<select>`）的下拉列表**——这是本次修的重点，浅色下不该是黑底白字 |
| 编辑器面板 | 打开一个文件，代码高亮配色在两套主题下都可读（这层是唯一保留手写 hex 的） |
| 传输队列浮层 | 进度条轨道与填充色协调 |
| 右键菜单 | 悬停项的背景色 |
| toast | 顶部提示的边框与底色 |
| 诊断报告 | 大段等宽文本的可读性 |

**特别确认**：浅色下如果**什么都没变**（还是深色），说明 `body[data-ds-dark-theme]` 没被宿主移除，是浅色层没激活——报给我。

## 2. 窄侧栏（本次新增的容器查询）

把侧栏拖到最窄（约 300px 以下）：

- 主机卡片的按钮行应该**换到标题下方**（而不是挤在右边被压扁）
- 区标题（「主机」「已挂载」）应该换行而不是溢出
- 再窄一些，卡片内边距收紧

**关键**：把**浏览器窗口拉宽**但**侧栏保持窄**。如果布局跟着窗口变而不是跟着侧栏变，说明容器查询没生效。

## 3. 键盘可达性（P3 补的）

用 `Tab` 走一遍，每一下都应该看得见焦点环：

- 文件面板里的**编辑按钮**（预览头部）
- 历史面板的**刷新按钮**
- **toast 本身**（提示出现时按 Tab 进去，应该有个环；按 Esc 关闭）
- 编辑器**标签页的名字**（不是旁边的 ×）
- 诊断分区的**折叠标题**

之前这些都没有焦点环，现在应该都有。焦点环不该被容器裁掉——如果哪个环只出现一半，报给我。

## 4. 动效（P4）

系统设置里打开「减少动态效果」（Windows：设置 → 辅助功能 → 视觉效果 → 动画效果 关掉），然后：

- 打开右键菜单、传输队列浮层、对话框 —— 都不应该有滑入/缩放动画
- 传输进行中的进度环 —— 不应该转
- 进度条 —— 不应该扫光

## 5. 滚动条（P4）

看这几处滚动时的滚动条：

- 面板整体
- 浏览器对话框的目录列表
- 传输队列列表
- 编辑器代码区
- 诊断报告的大文本框
- toast 展开的详情

应该是**细的、半透明灰的**，不是 Windows 默认的浅灰凹槽。深色主题下尤其明显。

## 6. 数字对齐（P4）

- 主机卡片上的**端口号**（多张卡片纵向比较，应该左对齐成列）
- 文件列表的**文件大小**
- 编辑器底部的**行号**
- 分页器的「1 / 3」

数字宽度应该一致，不随位数抖动。

## 7. 回归：确认没坏

- 传输一个大文件，进度、取消、完成后打开队列都对
- 右键菜单所有动作都能点
- 编辑器打开/保存/切换标签正常
- toast 的复制、详情、重试按钮正常

## 报给我的格式

哪个主题、哪个位置、期望 vs 实际。有截图最好。
如果第 1 条里浅色完全没变化，那是最高优先级——说明宿主信号名不对。
